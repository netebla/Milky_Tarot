# Changelog

Все значимые изменения в проекте документируются в этом файле.

## [Не опубликовано] - 2026-10-01

### Добавлено

- Отдельный бот поддержки с пользовательским и административным интерфейсами.
- Постоянные обращения, очередь `/tickets`, назначение ответственного администратора и reply-маршрутизация через Postgres.
- Передача текста и Telegram-вложений без раскрытия личных контактов администраторов.
- Закрытие и повторное открытие обращений, уведомления всем администраторам.
- Автоматическая миграция `003_support_bot.sql` и третий сервис в Docker Compose.

### Изменено

- «Помощь» в основном боте теперь ведёт в отдельного support-бота вместо личного контакта.

## [Не опубликовано] - 2025-01-XX

### Добавлено

#### Улучшенная система админ-рассылок

- **Выбор типа пуша при отправке рассылки**
  - После ввода текста пуша админ может выбрать один из трёх типов:
    - **Обычный пуш** — сообщение с главным меню
    - **Пуш с раскладом "Задать вопрос"** — сообщение с кнопкой "Начать расклад"
    - **Пуш с раскладом "Энергия года"** — сообщение с кнопкой "Узнать энергию года"
  - Возможность изменить тип пуша перед подтверждением отправки

- **Новые клавиатуры:**
  - `admin_push_type_kb()` — выбор типа пуша
  - `admin_push_year_energy_kb()` — кнопка "Узнать энергию года" для пуша

- **Новые обработчики:**
  - `cb_admin_push_type()` — обработчик выбора типа пуша
  - `cb_admin_push_type_back()` — возврат к выбору типа пуша
  - `cb_admin_push_year_energy()` — обработчик кнопки "Узнать энергию года" из пуша
    - Выполняет тот же функционал, что и кнопка "Энергия года" из главного меню
    - Доступен всем пользователям (не только админам)
    - Выбирает случайную карту, отправляет изображение и трактовку
    - Предлагает перейти к платному раскладу "Итоги года"

- **Новое состояние FSM:**
  - `AdminPushStates.waiting_push_type` — состояние ожидания выбора типа пуша

#### Расклад "Энергия года"

- **Новый бесплатный расклад "Энергия года"** (доступен только администраторам)
  - Кнопка в главном меню для админов: `Энергия года`
  - Случайный выбор одной из 22 карт старших арканов
  - Отправка изображения карты и трактовки архетипа года
  - Предложение перейти к платному раскладу "Итоги года" после получения трактовки

- **Новые модули:**
  - `src/utils/parse_year_energy.py` — парсер для преобразования docx файла с архетипами в CSV
  - `src/utils/year_energy_loader.py` — загрузчик данных архетипов года из CSV

- **Новые данные:**
  - `src/data/year_energy_archetypes.csv` — CSV файл с архетипами года (22 карты старших арканов)

- **Новые состояния FSM:**
  - `YearEnergyStates.waiting_selection` — состояние ожидания выбора для расклада "Энергия года"

- **Новые обработчики:**
  - `btn_year_energy()` — обработчик кнопки "Энергия года"
  - `cb_year_energy_deep_reading()` — обработчик перехода к платному раскладу

### Изменено

  - Добавлена кнопка "Энергия года" в главное меню (только для админов)

### Технические детали

**Парсинг данных:**
- Парсер извлекает названия карт из docx файла по паттерну "N Архетип — Название"
- Автоматическое сопоставление сокращённых названий с полными (например, "Жрица" → "Верховная Жрица")
- Удаление дубликатов и очистка данных
- Сохранение в CSV формат для удобной загрузки

**Логика расклада:**
- Выбор случайной карты из доступных архетипов
- Отправка изображения карты (локальный файл или URL)
- Отправка трактовки архетипа
- Предложение платного расклада с кнопкой перехода

**Интеграция с платным раскладом:**
- После бесплатной трактовки пользователь может перейти к платному раскладу "Итоги года"
- Проверка баланса рыбок (101 🐟)
- Автоматический запуск новогоднего расклада при достаточном балансе
